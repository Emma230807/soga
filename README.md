# soga
## Descripcion breve
SOGA es una apñlicacion dedicada a estudiantes y a maestros.
Ayudara al alumnno a organizarse permitiendole tener notas dentro de la aplicacion asi como ver,
agregar y llevar un mejor control de sus actividades.
Por parte de los profesores le ayudara para tener un mayor control en su grupo.
Podiendo ver que tareas les faltan a sus alumnos. 
En cambio el administardor podra dar de alta a los maestros 
## Manejo de estado
En SOGA se utiliza setState() para actualizar las pantallas cuando el usuario realiza alguna acción, como agregar tareas, completar actividades o seleccionar un grupo.
Se eligió setState() porque es fácil de utilizar, viene incluido en Flutter y permite actualizar la información de manera sencilla, sin instalar herramientas adicionales.
